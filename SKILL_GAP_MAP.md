# Skill Gap Map

This proof package is intentionally asymmetric.

## Stronger evidence
- shaping ambiguous problems into an implementable build;
- customer/operational context;
- implementation ownership;
- coding-agent orchestration and bounded repair;
- verification, acceptance and evidence controls;
- technical + non-technical communication.

## Skills being deepened
- cloud architecture and networking;
- production observability;
- API/data integration depth;
- AI-specific evals and error analysis;
- security patterns for customer-facing agent systems.

The goal is not to present as a senior ML engineer. The goal is to show a credible trajectory toward customer-embedded AI implementation and solution delivery.
