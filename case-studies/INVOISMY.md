# Case Study — InvoisMY (Sanitized)

## Problem
A compliance-heavy workflow needed integration behavior that failed safely and remained inspectable when external service conditions or input boundaries were wrong.

## Approach
The work used bounded changes, sandbox-only integration, deterministic preflight checks, explicit query/validation boundaries, retry/polling controls and evidence gates.

## What this proves
- translating compliance constraints into system behavior;
- agent-assisted iteration with deterministic verification;
- limiting production risk;
- preserving evidence for review.

## Public limitation
Private code and taxpayer/customer identifiers are not published. Demonstrate the repository and tests only in an authorized interview screen share.
