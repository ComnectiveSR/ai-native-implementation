# AI-Native Implementation Proof — Wei Sheng Lee

This is a sanitized proof package for customer-facing AI implementation, digital transformation, implementation consulting and solution-delivery roles.

It does not claim that AI wrote a certain percentage of my work. It shows how I define problems, shape specifications, use coding/research agents, verify results, control risk, and convert ambiguous requirements into working systems.

## Start here

1. `INTERVIEW_PROOF.md` — six common AI-era interview questions answered with shipped work and explicit limitations.
2. `case-studies/MNAVI.md` — compact implementation/debugging case.
3. `evidence/MNAVI_PROVIDER_STATUS_REPAIR.md` — observed failure, correction and verification evidence.
4. `HOW_I_WORK_WITH_AI.md` — human/agent operating model.
5. `demo/FIVE_MINUTE_SCREEN_SHARE.md` — interview walkthrough.
6. `PROOF_MATRIX.md` — wider evidence map.

## Core principle

The model is replaceable. The durable proof is:

**problem selection → context → specification → bounded execution → verification → failure recovery → human judgment → measurable operational value**

## Public boundary

No raw taxpayer, banking, guest, credential, production-customer, legal or other confidential data is included.

## What this repository does not claim

It does not present me as a senior ML engineer, enterprise architect, or full-stack AI infrastructure specialist. My current target is customer-embedded AI implementation and digital transformation: understand the operating problem, translate it into a workable system, coordinate delivery, verify the result, and improve the next deployment from what was learned.
