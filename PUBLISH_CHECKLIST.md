# Publication Checklist

Publish only after every item is true.

- Repository contains no credentials, raw taxpayer/customer data, guest data, private banking/legal evidence or sensitive identifiers.
- MNavi case can be understood without access to the private repository.
- Commit SHA and test counts match the source evidence.
- No claim of production scale, customer adoption, regulatory approval, ML-engineer depth or enterprise-architect ownership is made.
- README points to the strongest evidence first.
- LinkedIn Featured links to this repository after publication.
- First application batch starts the same day. Do not wait for more cases.
