# Beat the Baseline — Implementation Judgment Challenge

Purpose: demonstrate value beyond a generic one-shot model answer.

## Task
Take one messy SME workflow with incomplete records, multiple handoffs and a consequential approval decision.

## Baseline
Run a strong general model with a plain request to “automate/improve this workflow.” Save the answer.

## My implementation pass
Add:
- user/buyer distinction;
- current-state workflow;
- exact failure/exception paths;
- data sources and sensitivity;
- acceptance criteria;
- deterministic controls;
- human approval boundary;
- evidence/logging requirements;
- recovery path;
- success metric.

## Score both outputs 0–2 on each
1. Problem definition.
2. Requirement coverage.
3. Feasibility.
4. Privacy/security.
5. Traceability.
6. Exception/recovery handling.
7. Human accountability.
8. Business outcome measurability.

The proof is not “I am smarter than the model.” The proof is that disciplined context, judgment and verification produce a more deployable result.
